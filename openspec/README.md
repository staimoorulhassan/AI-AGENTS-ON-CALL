# OpenSpec Workspace

This project follows OpenSpec conventions:

- `openspec/changes/` holds proposed and in-progress changes.
- Each change folder includes `proposal.md`, `tasks.md`, optional `design.md`/`progress.md`, and `specs/<capability>/spec.md` deltas.
- `openspec/specs/` can hold current accepted specs after archiving changes.
